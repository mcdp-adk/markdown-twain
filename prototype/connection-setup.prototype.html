How should setting up an LLM connection feel?

Wayfinder ticket Prototype the LLM connection setup flow. The goal is "pick a provider, give it a key, pick a model, done". The question is which shape the saved configuration takes, and what the QuickPick flow on top of it feels like: A one connection, B one active provider that remembers its model and effort per provider, or C several named connections. Everything is simulated. Provider responses and model lists are fake, and nothing leaves this page. Each shape keeps its own state, so you can switch tabs and compare.
