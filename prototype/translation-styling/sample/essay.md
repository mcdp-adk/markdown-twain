# Why bilingual reading works

Reading a text in two languages at once sounds like a recipe for distraction. In practice, readers who are comfortable in the source language rarely read both versions line by line. They skim the translation to get their bearings, then return to the original for the parts that matter, such as a precise definition, a code sample, or a sentence whose tone they want to hear first-hand.

## The translation should step back

A bilingual layout succeeds when the eye can tell the two languages apart without effort. If the translation looks exactly like the original, every paragraph becomes a small puzzle: which one am I reading? If it looks too different, the page feels like two documents fighting for attention.

> Good typography is invisible. Bad typography is everywhere.
>
> The same holds for a translation layer: nobody should notice it until they need it.

### Colour, size, or position

There are only a few levers to pull:

1. **Colour** separates the languages at a glance, but it has to work on both light and dark themes.
2. **Size** makes the translation feel secondary, at the cost of readability for long passages.
3. **Position** keeps each translation next to its source, so the reader never has to search for it.

Most tools combine all three. The hard part is headings, where the translation competes with the heading's own weight and rule, and tables, where there is little room for a second line.
